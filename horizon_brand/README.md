# Horizon — Brand Developer Package

This package contains the Horizon Prediction Market logo/icon assets prepared for web and app development.

## Included

### Source PNG artwork
`assets/png/`
- cyan_sunrise_wave_emblem.png
- cyan_sunrise_waves_app_icon.png
- neon_horizon_fintech_icon.png
- navy_horizon_sunset_emblem.png
- white_sunset_horizon_emblem.png
- neon_blue_sunrise_wave_emblem.png
- horizon_prediction_market_logo.png

### SVG
`assets/svg/`
- One SVG counterpart for every PNG.
- These preserve the exact generated artwork by embedding the original PNG inside an SVG container.

### Native vector
`assets/svg-vector/horizon-brandmark-native-vector.svg`
- A clean geometric vector rebuild of the core Horizon brandmark.
- This version uses native SVG gradients and paths and can be edited directly in Figma, Illustrator, Sketch, or code.

### Favicons
`favicons/`
- favicon.ico
- 16x16
- 32x32
- 48x48
- 64x64

### App / PWA icons
`app-icons/`
- Apple touch icon: 180x180
- PWA icons: 192x192 and 512x512
- High-resolution icon: 1024x1024
- Maskable PWA icon: 512x512

### Web manifest
`manifest.webmanifest`

## Core palette
- Deep navy: `#031B47`
- Mid blue: `#063A82`
- Cyan: `#1CDDEB`
- Light aqua: `#A8FFF9`

## Notes
The appearance-preserving SVG files are SVG containers around the generated raster artwork, so they look identical to the PNG source but are not fully editable vector paths. For a true scalable/editable asset, use `horizon-brandmark-native-vector.svg`.
